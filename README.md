A program that copies one image summing up the world news of Thursday 26 November 2026 to /output/entry.png. The image is a newspaper-style front page: the Houthi strike on a Saudi refinery with oil topping $94, the US tariff wave, sliding markets, the first foreign astronaut on China's space station, and the Cairo tanker fire.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
